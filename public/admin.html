선물 목록

전체 0설명 있음 0저장 안 된 변경 있음

채팅창의 '오늘의 선물'에서 이 목록 중 하나가 무작위로 나와요. 이름은 40자, 설명은 120자까지예요.
이름·설명을 고치면 이미 열린 선물에도 바로 반영돼요. 줄을 지우면 그 선물은 더 이상 나오지 않아요(이미 연 기록은 남아요).
문구에 넣을 수 있는 이름 태그: {A} 선물을 연 사람 · {B} 상대 · {C} 가입 코드를 받은 사람 · {D} 짝꿍 코드로 들어온 사람
태그 바로 뒤에 붙인 조사는 이름 받침에 맞춰 바뀌어요: {B}가 → 라차가 / 트리스탄이, {B}를 → 라차를 / 트리스탄을, {B}와 · {B}는 · {B}로 · {B}야(부르는 말)도 같아요. '~이다' 꼴은 {B}이야 · {B}이에요 · {B}이랑처럼 '이'를 붙여 쓰면 받침 없는 이름에선 '이'가 빠져요.

아직 저장한 목록이 없어서, 사이트는 코드에 들어 있는 기본 선물 목록을 쓰고 있어요. 여기서 목록을 저장하면 그때부터 이 목록을 써요.

시트에서 한꺼번에 넣기 · 고치기

스프레드시트에서 A열 선물 · B열 설명을 골라 복사(Ctrl/⌘+C)한 뒤 아래에 붙여 넣어요. 첫 줄이 '선물'이면 제목 줄로 보고 건너뛰어요.
목록 끝에 추가: 새 줄만 덧붙여요.  전체 바꾸기: 붙여 넣은 내용이 새 목록이 돼요(이름이 같은 줄은 같은 선물로 이어져서, 이미 연 선물의 설명이 새 설명으로 바뀌어요).
지금 목록을 시트에서 고치려면 시트용으로 복사 → 시트에 붙여 넣고 수정 → 다시 복사해서 전체 바꾸기.
